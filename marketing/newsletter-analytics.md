# Newsletter Analytics Setup

## Tracking

### UTM Parameters
Aggiungere alle URL nella newsletter:
```
?utm_source=newsletter
&utm_medium=email
&utm_campaign=myzubster-[DATA]
&utm_content=[SEZIONE]
```

### Metriche Chiave
- **Open Rate**: Target > 25%
- **Click Rate**: Target > 5%
- **Unsubscribe Rate**: Target < 1%
- **Subscriber Growth**: Target +10/settimana

### A/B Testing
Testare:
1. Oggetto: breve vs descrittivo
2. Orario invio: mattina vs sera
3. CTA: "Scopri di piu" vs "Prova ora"
4. Layout: testo vs HTML

### Strumenti Consigliati
- Substack (gratuito)
- Mailchimp (freemium)
- ConvertKit (per creator)
