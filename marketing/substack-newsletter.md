## Template Newsletter #2: Bounty Program

**Corpo**:

Ciao!

Questa settimana voglio parlarti del nostro programma bounty: il modo piu semplice per guadagnare crypto contribuendo a un progetto open-source.

### Come Funziona

1. Vai su github.com/MyZubster-Ecosystem/MyZubsterGateway/issues
2. Cerca le issue con label "bounty"
3. Commenta /attempt per prenotare
4. Sviluppa la feature
5. Apri una Pull Request
6. Ricevi MYZ dopo il merge
