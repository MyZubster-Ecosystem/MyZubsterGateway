MyZubsterGateway API

Complete REST API reference for the MyZubster decentralized gateway. All endpoints require authentication via JWT Bearer token except where noted.

👥 Users

GET/api/users

List all registered users with their profiles and reputation scores.

curl -X GET https://api.myzubster.com/api/users \
  -H "Authorization: Bearer ***"

🏛️ Comuni (Municipalities)

GET/api/comuni

Elenco di tutti i comuni registrati. Restituisce un array di oggetti comune con nome, regione, e popolazione.

curl -X GET https://api.myzubster.com/api/comuni \
  -H "Authorization: Bearer ***"
GET/api/comuni/:id

Dettaglio di un comune specifico per ID. Include statistiche e servizi attivi.

🏢 Enti (Entities)

GET/api/enti

Elenco di tutti gli enti (aziende, associazioni, organizzazioni) registrati. Filtrabili per categoria.

curl -X GET https://api.myzubster.com/api/enti \
  -H "Authorization: Bearer ***"
GET/api/enti/:id

Dettaglio di un ente specifico per ID. Include reparti, progetti e contatti.

🌱 Orti Urbani (Urban Gardens)

GET/api/orti

Elenco di tutti gli orti urbani disponibili. Ogni orto include posizione, superficie, e stato di assegnazione.

curl -X GET https://api.myzubster.com/api/orti \
  -H "Authorization: Bearer ***"
GET/api/orti/:id

Dettaglio di un orto urbano per ID. Include storico assegnazioni e colture attive.

📊 Statistics

GET/api/stats

Statistiche aggregate della piattaforma: utenti attivi, transazioni, orti assegnati, e volume reward.

curl -X GET https://api.myzubster.com/api/stats \
  -H "Authorization: Bearer ***"

🪙 Tokens

GET/api/tokens

Elenco di tutti i token disponibili (MYZ, XMR, BENZINA, etc.) con saldi e storico transazioni.

curl -X GET https://api.myzubster.com/api/tokens \
  -H "Authorization: Bearer ***"
GET/api/tokens/:id

Dettaglio di un token specifico per ID. Include prezzo, fornitura, e storico.

📅 Bookings

GET/api/bookings

Retrieve all bookings. Returns an array of booking objects.

curl -X GET https://api.myzubster.com/api/bookings \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json"
POST/api/bookings

Create a new booking. Required fields: serviceId, userId, date.

curl -X POST https://api.myzubster.com/api/bookings \
  -H "Authorization: Bearer ***" \
  -H "Content-Type: application/json" \
  -d '{"serviceId":"123","userId":"456","date":"2026-08-10"}'

💰 Bounties

GET/api/bounties

List all available bounties with filtering by category, difficulty, and reward range.

POST/api/bounties/:id/claim

Claim a bounty. Locks the bounty to your account for 48 hours.

🌐 Gateway

GET/api/health

Health check endpoint. Returns gateway status, uptime, and service metrics. No auth required.

  "version": "2.4.1",

    "database": "ok",
    "redis": "ok",
    "tari_node": "synced"
  }
}
