# API Reference

## Autenticazione
- `POST /api/auth/register` - Registrazione utente
- `POST /api/auth/login` - Login

## Pagamenti
- `POST /api/payment/myz/create` - Crea pagamento MYZ
- `POST /api/payment/xmr/create` - Crea pagamento XMR

## Orti Francescani
- `POST /api/orti-francescani/register` - Registra orto
- `POST /api/orti-francescani/:id/plants` - Registra pianta
